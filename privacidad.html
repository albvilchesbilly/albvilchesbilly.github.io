Política de privacidad de asistente-radar

Última actualización: 15 de octubre de 2026

Quién la usa

asistente-radar es una aplicación de uso personal. Tiene un único usuario, su propietario, que es quien la ha creado y quien concede el acceso a su propia cuenta de Gmail. No se ofrece a terceros.

Qué datos usa

Con el permiso de solo lectura de Gmail, la aplicación lee los correos recibidos en las últimas 24 horas, excluyendo spam y promociones. Con el permiso de envío, manda un único aviso diario a la cuenta del propio usuario. No lee contactos, calendario ni ningún otro dato de Google.

Antes de cualquier análisis, la aplicación elimina el asunto y el contenido de los correos que parecen nóminas, documentación fiscal o bancaria: de esos correos no sale ningún contenido hacia servicios externos.

Cómo se procesan

Del resto de correos se envían el remitente, el asunto y un extracto breve a la API de Anthropic para redactar el aviso, conforme a las condiciones de uso de esa API. La aplicación se ejecuta en Google Cloud, en la región de Madrid.

Qué se guarda

Se guarda un identificador y una huella de cada correo ya revisado, para no repetir avisos, y el texto de los avisos generados. No se guarda una copia de los correos. Las credenciales de acceso se guardan cifradas en Google Secret Manager.

Con quién se comparten

Con nadie. Los datos no se venden, no se usan para publicidad y no se transfieren a terceros, salvo el procesamiento descrito con Anthropic.

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado.

Cómo retirar el permiso

El acceso se revoca en cualquier momento desde myaccount.google.com/permissions. Al revocarlo, la aplicación deja de poder leer y enviar correo de inmediato.
